# E-Commerce Customer Churn Predictor

A machine learning project that predicts which e-commerce customers are likely to stop buying, and explains *why*. It includes a full training pipeline (class balancing, model benchmarking, cross-validation) and an interactive Streamlit dashboard for single-customer and bulk predictions with SHAP explainability.

---

## Features

- **End-to-end training pipeline** (`train.py`): data cleaning, encoding, stratified split, SMOTE balancing, and benchmarking of three models.
- **Class imbalance handling**: only ~17% of customers in the dataset churn, so SMOTE is applied to the training split to balance the classes.
- **Model benchmarking**: Logistic Regression, Random Forest, and XGBoost are compared using 5-fold cross-validation and a held-out test set (accuracy, precision, recall, F1).
- **Real-time customer profiler**: enter a customer's details in a form and get a churn / safe verdict with a probability score.
- **SHAP explainability**: a bar chart of the top 10 features driving each individual prediction, so the result isn't a black box.
- **Bulk batch prediction**: upload a `.csv` or `.xlsx` file of customers, get churn predictions and probabilities for every row, see the share of flagged customers, and download the full report as CSV.
- **Reusable inference module** (`src/predictor.py`): a `ChurnPredictor` class that loads saved artifacts and applies the exact same preprocessing used in training.

## Dataset

The project uses an e-commerce customer dataset of **5,630 customers** with **18 predictive features** and a binary `Churn` target (about 16.8% churned, 83.2% retained).

> **Note:** `data/ecommerce_churn.csv` is actually an Excel workbook (with `Data Dict` and `E Comm` sheets) saved with a `.csv` extension. `train.py` handles this automatically: it tries to read it as Excel first and falls back to CSV.

| Category | Features |
|---|---|
| Customer profile | `Tenure`, `Gender`, `MaritalStatus`, `CityTier`, `NumberOfAddress` |
| App and device usage | `PreferredLoginDevice`, `HourSpendOnApp`, `NumberOfDeviceRegistered` |
| Shopping behavior | `PreferedOrderCat`, `PreferredPaymentMode`, `OrderCount`, `DaySinceLastOrder`, `OrderAmountHikeFromlastYear` |
| Incentives | `CouponUsed`, `CashbackAmount` |
| Experience | `SatisfactionScore`, `Complain`, `WarehouseToHome` |

`CustomerID` is dropped before training.

---

## How It Works

1. **Load data**: reads the dataset (Excel or CSV) and drops `CustomerID`.
2. **Clean**: missing categorical values are filled with the mode, and missing numeric values with the median.
3. **Encode**: categorical columns are label-encoded, and the encoders are saved for use at inference time.
4. **Split**: an 80/20 stratified train/test split preserves the churn ratio.
5. **Balance**: SMOTE oversamples the minority (churn) class in the training set only, leaving the test set untouched.
6. **Benchmark**: Logistic Regression, Random Forest, and XGBoost are each evaluated with 5-fold cross-validation, then scored on the held-out test set.
7. **Save**: the XGBoost model, feature list, and encoders are saved to `saved_models/`, and the app uses them for predictions.

## Model Results

Results from running `python train.py` (`random_state=42`):

| Model | CV Accuracy | CV F1 | Holdout Accuracy | Holdout Precision | Holdout Recall | Holdout F1 |

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/rizwanwebofficial-bot/Ecommerce-Customer-Churn-Predictor.git
cd Ecommerce-Customer-Churn-Predictor
```

### 2. Create a virtual environment and install dependencies

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Train the model

`saved_models/` is git-ignored, so you need to generate the model files locally first:

```bash
python train.py
```

This prints the class balance, the model comparison table, and saves the artifacts to `saved_models/`.

### 4. Launch the app

```bash
streamlit run app.py
```

## Using the App

### Individual Customer Profiler
Fill in the customer's details (tenure, login device, payment mode, satisfaction score, complaints, cashback, and so on) and click **Generate Predictive Analysis & SHAP Breakdown**. You get:
- a verdict: **High Churn Vulnerability** or **Account Profile Classified Safe**
- the churn probability as a percentage
- a SHAP bar chart of the top 10 factors behind the decision

### Bulk Batch Ingestion
Upload a `.csv` or `.xlsx` file with one customer per row. The app:
- runs every row through the same preprocessing used in training
- adds `Churn_Prediction` (`Churn Risk` / `Retained`) and `Churn_Probability` columns
- shows the number and percentage of flagged customers
- previews the first 100 rows and lets you download the full report as `Customer_Churn_Inference_Report.csv`

Your file should include a `CustomerID` column (used in the results preview) and the feature columns listed in the Dataset section. Missing columns and values are filled automatically with defaults.

## Using the Predictor in Your Own Code

```python
import pandas as pd
from src.predictor import ChurnPredictor

predictor = ChurnPredictor()
predictor.load()

df = pd.read_csv("new_customers.csv")
X = predictor.preprocess_input(df)
predictions, probabilities = predictor.predict(X)
shap_values = predictor.explain(X)
```
